# 懒得找了 · 云端总控台使用说明文档 (Console README)

本控制台专为「懒得找了」Android 客户端设计，支持通过可视化的 **Web 控制台** 或终端的 **Python CLI 命令行程序** 实时管理软件全部内容，并推送新版本触发本体软件的实时更新弹窗。

---

## 🌟 核心运行机制

1. **云端中枢**：控制台对接 GitHub 仓库 `shuting52/16-47-2026-09-20` 中的 `admin-data.json` 作为唯一真相源。
2. **凭据预置**：控制台已预置安全 Access Token（支持环境变量 `GITHUB_TOKEN` 或内置自动加载），无需繁琐配置，开箱即连。
3. **实时感知与弹窗触发**：
   - 本体 Android 客户端内置后台静默检测，每 20 秒与云端比对最新版本。
   - 用户在客户端【设置】页面点击【检查更新】时，即刻发起实时云端比对。
   - 当控制台选择 **「🚀 推送并触发本体更新弹窗」** 时，系统会自动将 `versionCode` 递增，本体客户端感知到版本代码增加后，**即刻在界面正中弹出高定制的更新提示弹窗**！
   - 若选择 **「💾 仅静默同步」**，数据将在客户端下次刷新时无感应用，不打扰用户。

---

## 🖥️ 两种控制台运行方式

### 方式一：Web 可视化控制台 (推荐，界面直观，功能最全)

1. 双击或使用任意现代浏览器打开项目中的 `console/index.html`。
2. 页面已自动填充 Token 与仓库信息，并在打开 0.2 秒后**自动连接云端**加载数据。
3. 底部导航包含 8 大功能专区：
   - 🏠 **首页**：分类增删、子分类、站点增删、角标文字/色彩、上下排序。
   - 📦 **软件**：本地上传 APK、获取下载直链、配置作者/标签/预览图。
   - 🧠 **Skill**：本地上传预览图/图片/视频、完整编辑多行 Prompt 提示词。
   - ⚙️ **设置**：管理 App 名称、Slogan、关于文本、官方联系群/二维码。
   - ✨ **开屏**：输入自定义 HTML/CSS/JS 代码控制开屏、上传开屏图片/视频。
   - 👋 **欢迎**：开启/停用欢迎弹窗、添加新特性列表、上传功能配图。
   - 🔄 **更新**：编辑更新标题/日志/按钮、强制更新、自定义 CSS/HTML 样式代码。
   - 🚀 **APK 仓库**：本地打包指引、本地上传 APK、自动检测仓库已有 APK、一键设为最新并触发更新。

### 方式二：Python 命令行控制台 (终端/服务器/脚本自动化)

在终端运行以下命令：

```bash
# 启动交互式菜单控制台
python3 console/console.py

# 快速检测仓库中的 APK 安装包
python3 console/console.py --check-apks

# 查看云端连接与当前版本状态
python3 console/console.py --status

# 一键递增版本代码并发布更新弹窗
python3 console/console.py --bump-version "新增多项实用工具，性能大幅优化"

# 一键上传本地打包好的 APK 并触发本体更新弹窗
python3 console/console.py --upload-apk app/build/outputs/apk/debug/app-debug.apk
```

## 📋 八大功能模块详细操作说明

### 1. 首页管理
- **增删分类**：点击【＋ 新增分类】，填写英文 ID（如 `ai_tools`）、显示名称、图标 Key（如 `grid`, `sparkle`, `star` 等），点击保存。
- **管理站点与角标**：
  - 点击分类进入站点列表，点击【＋ 站点】添加网站名称、URL、描述。
  - **角标设置**：支持填写角标文字（如 `NEW`、`HOT`、`独家`、`站长推荐`），并选择色彩样式（`ROSE` 玫瑰红、`NEW` 翠绿、`GOLD` 金黄、`BLUE` 科技蓝）。
- **推送到本体**：
  - 点击【🚀 推送并触发本体更新弹窗】：递增版本代码并推送，客户端即刻弹窗提醒用户首页已更新！
  - 点击【💾 静默保存发布】：云端同步保存，用户刷新分类即生效，不弹窗。

### 2. 软件管理
- **本地上传 APK**：点击【＋ 新增软件】或点击编辑，在【本地上传 APK 文件】区域选择本地 `.apk` 文件，控制台自动调用 GitHub API 将安装包上传至仓库 `dist/apk/` 目录，并自动生成全球 CDN 直链。
- **元数据配置**：可配置软件名称、官网链接、作者、角标标签，以及本地上传界面预览截图。
- **推送到本体**：保存后点击【🚀 推送并触发本体更新弹窗】。

### 3. Skill 技能库与 Prompt 提示词
- **媒体文件上传**：
  - 支持本地上传技能【预览图/图片】（JPG/PNG/GIF/WebP）。
  - 支持本地上传技能【演示视频】（MP4/WebM/MOV）。
- **Prompt 提示词编辑**：
  - 拥有专属多行代码编辑器，支持完整编写、排版和调试各种复杂的大模型 Prompt 提示词，无字数限制。
- **推送到本体**：点击【🚀 推送并触发本体更新弹窗】，客户端 Skill 版块即刻刷新。

### 4. 设置版块管理
- 可以全面管理 Android 客户端【设置】页面展示的所有内容：
  - App 标题（默认「懒得找了」）与副标题 Slogan
  - 【关于我们】图文详细介绍
  - 官方交流 QQ 群链接/二维码、微信二维码、赞赏码图片等
- 修改完成后点击【🚀 推送并触发本体更新弹窗】即可同步。

### 5. 开屏动画管理 (支持自定义代码控制)
- **三种开屏模式**：
  1. **默认模式**：精美 3D 方块旋转、渐变流光文字与科技感呼吸环。
  2. **自定义代码模式（核心特性）**：支持在文本框中直接输入任意 HTML5 + CSS3 + JavaScript 动效代码！客户端将通过硬件加速全屏 WebView 完整呈现您的开屏动效！页面内可点击【👁️ 预览代码】先在浏览器中预览效果。
  3. **媒体开屏模式**：支持本地上传全屏海报图片或短视频动画作为开屏。
- 可调节开屏展示时长（1-15秒）与底层背景色。
- 点击【🚀 推送并触发本体更新弹窗】后，客户端下次冷启动即可应用全新开屏！

### 6. 欢迎界面弹窗
- **功能定位**：用户安装新版本或新特性上线时，用于首次启动弹出全新功能速递。
- **配置项**：
  - 开启/停用开关
  - 弹窗大标题（如「欢迎体验 2.0 全新架构」）
  - 新功能列表说明（支持多行条列展示）
  - 本地上传宣传配图
  - 自定义主按钮文案（如「立即探索」）
- 点击【🚀 推送并触发本体更新弹窗】即刻下发。

### 7. 更新弹窗管理 (深度定制 UI 与样式)
- **常规更新设置**：
  - 设置 `versionName`（如 `2.1.0`）与 `versionCode`。
  - 编辑弹窗标题与多行更新日志。
  - 设置确认更新按钮与取消按钮文字。
  - 开启/关闭【强制更新】模式。
  - 配置最新版 APK 下载直链。
- **自定义样式代码（进阶）**：
  - **自定义 CSS 代码**：可输入 CSS 样式规则注入覆盖默认弹窗样式（如调整圆角、边框发光、按钮渐变色彩）。
  - **自定义 HTML/JS 代码**：支持完全使用自定义网页结构接管更新弹窗交互！
- 点击【🚀 发布新版本并立即触发本体更新】即可一键生效。

### 8. APK 制作与仓库管理
- **① 本地打包制作指南**：
  - 运行 `gradle assembleDebug` 生成测试包：`app/build/outputs/apk/debug/app-debug.apk`
  - 运行 `gradle assembleRelease` 生成正式签名包。
- **② 本地 APK 上传仓库**：
  - 在【本地上传 APK 至 GitHub 仓库】中选取打包生成的 APK，自动分块上传至 GitHub 仓库的 `dist/apk/` 目录。
- **③ 自动检测仓库更新内容**：
  - 控制台自动调用 GitHub API 查询 `dist/apk/` 目录，列出仓库中全部 APK 文件、文件大小、SHA 与下载链接。
- **④ 一键设为最新发布版本**：
  - 点击仓库列表中任一 APK 的【设为最新并触发本体更新】，控制台会自动关联其直链并递增版本代码，**本体软件立即触发更新弹窗**！
